# 🤖 AI સ્માર્ટ ઓનલાઇન ફોર્મ ઓટો-ફિલર (AI Smart Universal Form Auto-Filler)

આ સોફ્ટવેર કોઈપણ ઓનલાઇન ફોર્મ (સરકારી ભરતી, પરીક્ષા, કોલેજ એડમિશન, જોબ એપ્લિકેશન, ગૂગલ ફોર્મ્સ) ૧-ક્લિકમાં આપમેળે ભરી આપે છે.

---

## 🌟 મુખ્ય વિશેષતાઓ (Features):

1. **ઉમેદવાર પ્રોફાઇલ મેનેજર (Candidate Profile Vault)**:
   - ઉમેદવારની તમામ અંગત વિગતો: નામ, પિતાનું નામ, અટક, જન્મ તારીખ, જાતિ (લિંગ), કેટેગરી (General/OBC/SC/ST/EWS).
   - સંપર્ક વિગતો: મોબાઈલ નંબર, વૈકલ્પિક ફોન, ઈમેઈલ, સરનામું, ગામ/શહેર, તાલુકો, જિલ્લો, રાજ્ય, પિનકોડ.
   - ઓળખ પુરાવા: આધાર કાર્ડ નંબર, પાન કાર્ડ નંબર, ચૂંટણી કાર્ડ.
   - બેંક વિગતો: બેંકનું નામ, ખાતા નંબર, IFSC કોડ.
   - શૈક્ષણિક વિગતો: ધોરણ ૧૦, ૧૨, ગ્રેજ્યુએશન ડિગ્રી, યુનિવર્સિટી, પાસ વર્ષ, ટકાવારી.
   - **ડોક્યુમેન્ટ્સ અને ફાઇલો**: પાસપોર્ટ સાઇઝ ફોટો, ઉમેદવારની સહી, આધાર કાર્ડ, માર્કશીટ વગેરે ફાઇલો અપલોડ કરી શકાય છે.

2. **AI આધારિત સ્માર્ટ ફોર્મ ફિલર (Smart Auto-Filler Engine)**:
   - ગૂગલ ક્રોમ (Google Chrome) બ્રાઉઝર તમારી સામે ઓટોમેટિક ખુલે છે.
   - ફોર્મના તમામ ટેક્સ્ટબોક્સ, ડ્રોપડાઉન, રેડિયો બટન અને ચેકબોક્સ ઓળખીને ઉમેદવારની સાચી વિગતો ભરી દે છે.
   - **ફાઈલ અપલોડ**: ફોટો અને સહી આપમેળે વેબસાઇટના અપલોડ બોક્સમાં જોડી (upload) આપે છે.
   - જે પણ બોક્સ ભરાયા હશે તે લીલા રંગની લાઇન (Green highlight) સાથે હાઇલાઇટ થશે.
   - બ્રાઉઝર તમારી સામે ખુલ્લું રહેશે જેથી તમે કેપ્ચા (Captcha) ભરી શકો અને આખરી ચકાસણી કરીને સબમિટ કરી શકો.

3. **બિલ્ટ-ઇન ટેસ્ટ પોર્ટલ (Live Demo Application Portal)**:
   - અસલ સરકારી ભરતી ફોર્મ જેવું ટેસ્ટ પોર્ટલ સોફ્ટવેરમાં અંદર જ સામેલ છે જેથી તમે તરત જ ચકાસી શકો.

## 🚀 કેવી રીતે શરૂ કરવું? (How to Run):

### રીત ૧: ૧-ક્લિક બેચ ફાઇલ વડે (ખૂબ સરળ)
`d:\ai-auto-video-editor\run_form_filler.bat` ફાઇલ પર ડબલ-ક્લિક કરો. 
તે આપમેળે સોફ્ટવેર ચાલુ કરીને તમારા બ્રાઉઝરમાં ખોલી દેશે.

### રીત ૨: કમાન્ડ પ્રોમ્પ્ટ / ટર્મિનલ વડે:
```bash
cd d:\ai-auto-video-editor\ai_form_filler
python app.py
```
બ્રાઉઝરમાં ઓપન કરો: `http://127.0.0.1:5000`

## 📝 ફોર્મ ભરવાની રીત (Step-by-step Guide):

1. **ઉમેદવાર ઉમેરો**:
   - "નવો ઉમેદવાર ઉમેરો" બટન દબાવો.
   - ઉમેદવારની વિગતો ભરો અને ફોટો તથા સહી અપલોડ કરો.
   - (અથવા ટેસ્ટ કરવા માટે ઉપર આપેલ **"ડેમો પ્રોફાઇલ લોડ કરો"** બટન દબાવો).

2. **લિંક દાખલ કરો**:
   - "ફોર્મની વેબસાઇટ લિંક" માં જે વેબસાઇટનું ફોર્મ ભરવું હોય તેની લિંક પેસ્ટ કરો.
   - (પહેલી વાર ટેસ્ટ કરવા માટે **"બિલ્ટ-ઇન ટેસ્ટ ફોર્મ"** બટન પર ક્લિક કરો).

3. **ઓટો-ફિલ બટન દબાવો**:
   - **"ઓટોમેટિક ફોર્મ ભરો (Start Auto-Fill)"** બટન દબાવો.
   - ક્રોમ બ્રાઉઝર ખુલશે અને ૧ સેકન્ડમાં તમામ ફીલ્ડ અને ફાઇલો ભરાઈ જશે!
   - તમારી નજર સામે જ ફોર્મ તૈયાર થઈ જશે, ચકાસીને સબમિટ કરી દો!
